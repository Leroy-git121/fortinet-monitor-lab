Fortinet VM64-KVM Traffic Monitoring Lab 🚦

Welcome to my hands-on Fortinet firewall network monitoring project! This lab is designed to demystify and showcase how to actively track, visualize, and analyze traffic in a simulated enterprise network using EVE-NG and FortiGate’s comprehensive monitoring tools.
🚀 Project Overview

Ever wondered how network pros see what's happening on the wire? This lab brings those skills to life with:

    A Fortinet VM64-KVM firewall deployed in EVE-NG

    Real multi-segment LAN/WAN setup

    Traffic flows, session stats, and live endpoint monitoring

🎯 Key Objectives

    Deploy Fortinet VM and configure interfaces (WAN & LAN)

    Set up DHCP for clients and manage their leases easily

    Create, monitor, and enforce firewall/security policies

    Use FortiView and logs for intuitive, real-time network visibility
